## 练习1

**题目**：
对于任意实数a，下列各式一定成立的是（ ）
A. $\sqrt{a^2 - 4} = \sqrt{a - 2} \cdot \sqrt{a + 2}$
B. $\sqrt{(a - 8)^2} = a - 8$
C. $\sqrt{-9 \cdot (-a)^3} = -3 \sqrt{-a}$
D. $\sqrt{36a^6} = 6a^3$

**答案**：D

**解析**：
①使用方法：平方根的性质和定义域分析
②关键步骤：分析每个选项的定义域和等式成立的条件
③为什么这样做：平方根函数有定义域限制，且$\sqrt{x^2} = |x|$，需要考虑这些性质

具体分析：
A. 只有当$a \geq 2$时才成立，不是对任意实数a成立
B. 应为$\sqrt{(a - 8)^2} = |a - 8|，只有当$a \geq 8$时才等于$a - 8$
C. 只有当$a \leq 0$时才有意义，且计算结果应为$3\sqrt{-a}$，不是$-3\sqrt{-a}$
D. $\sqrt{36a^6} = 6|a^3| = 6a^2|a|$，但$a^3$的符号不影响$a^2$，所以$\sqrt{36a^6} = 6a^3$对任意实数a都成立

**考查知识点**：
1. 平方根的定义域
2. 平方根的性质：$\sqrt{x^2} = |x|$
3. 绝对值的性质
4. 代数表达式的化简

## 练习2

**题目**：
下列等式中，对于所有实数a都成立的是（ ）
A. $\sqrt{a^2 + 2a + 1} = a + 1$
B. $\sqrt{a^2 - 4a + 4} = a - 2$
C. $\sqrt{a^2 + 9} = \sqrt{a + 3i} \cdot \sqrt{a - 3i}$
D. $\sqrt{a^2 + 4a + 4} = |a + 2|$

**答案**：D

**解析**：
①使用方法：完全平方公式和平方根的性质
②关键步骤：识别完全平方公式并应用平方根的定义域性质
③为什么这样做：需要将表达式化为完全平方形式，然后应用$\sqrt{x^2} = |x|$的性质

具体分析：
A. $\sqrt{a^2 + 2a + 1} = \sqrt{(a + 1)^2} = |a + 1|$，只有当$a \geq -1$时才等于$a + 1$
B. $\sqrt{a^2 - 4a + 4} = \sqrt{(a - 2)^2} = |a - 2|$，只有当$a \geq 2$时才等于$a - 2$
C. 引入了复数，题目限定在实数范围内讨论
D. $\sqrt{a^2 + 4a + 4} = \sqrt{(a + 2)^2} = |a + 2|$，对任意实数a都成立

**考查知识点**：
1. 完全平方公式
2. 平方根的性质：$\sqrt{x^2} = |x|$
3. 绝对值的定义
4. 代数表达式的因式分解
